# Risk of The Borderlands - updates

This repository only holds the update releases that the Risk of The Borderlands launcher downloads by itself.

Each release is a signed manifest (`manifest.txt`, `manifest.sig`) and the files it names, each stored under its SHA-256.
The launcher takes an update only if the manifest is signed by the mod's maker and every file matches its hash.

These are the mod's own files only: its plugin, its launcher and its own data. No Borderlands game files are here.

To play, use the launcher you were given: it checks this page and offers each update.
